Make your own · with any AI

Ask Claude or ChatGPT for an app.

Your AI writes a Tinkrum app file: the lists, pages and style of a new app. You paste it into Tinkrum. It never contains your data, and you can undo it.

  1. Give it the guide

    Download the guide and attach it to a new chat. It tells the AI exactly what Tinkrum can draw.

    Download the guide

    If your AI can run code (ChatGPT and Claude usually can), attach the checker too. The AI runs it on its own file and fixes what it finds before you see it.

    Download the checker

  2. Say what you want

    In your own words. For example:

    Using the attached Tinkrum guide, make me a Tinkrum app file to track my plants: when I water them, which room they're in, and a reminder every Sunday. Run the attached tinkrum-check.js on it and fix everything until it says OK.

  3. Paste it into Tinkrum

    Copy the JSON it gives you. In Tinkrum, open Settings → My presets → Paste from clipboard. You see what it adds before it is added.

Don't share anything private with the AI: it only needs to know what you want to keep track of, not the entries themselves. For developers: JSON Schema · example app file.
